# Laser Plus — Web V4.0 Premium / Parte 1

Sitio estático listo para GitHub y Cloudflare Pages.

## Archivos
- `index.html`: página principal.
- `assets/css/style.css`: diseño y adaptación móvil.
- `assets/js/main.js`: menú, animaciones y galería.
- `assets/img/`: fotografías optimizadas en WebP.
- `robots.txt` y `sitemap.xml`: base SEO.

## Subir a GitHub
1. Abre el repositorio `laserplus-web`.
2. Selecciona **Add file > Upload files**.
3. Abre esta carpeta y arrastra **el contenido interior**, no el archivo ZIP.
4. Confirma que `index.html` quede en la raíz del repositorio.
5. Escribe `Versión 4.0 Premium - Parte 1` y pulsa **Commit changes**.
